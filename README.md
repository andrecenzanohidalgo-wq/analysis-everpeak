# Latin America Mobility & Economy Analysis – Sprint 5

Este repositorio contiene el análisis desarrollado durante el Sprint 5 del bootcamp de Data Analyst.

El proyecto analiza la relación entre la movilidad urbana y la productividad económica en las principales ciudades de Latinoamérica mediante la integración de datos del **TomTom Traffic Index** y **OECD Cities**. A lo largo del análisis se realiza la limpieza, transformación y combinación de ambos conjuntos de datos para obtener un dataset unificado que permita identificar patrones e insights relevantes.

## 📂 Contenido del repositorio

- `notebooks/S5_ladb_mobility_economy_project.ipynb`
  → Notebook principal con todo el proceso de limpieza, exploración, integración de datos, análisis y conclusiones.

- `data/`
  → Archivos originales utilizados durante el proyecto.

- `ladb_mobility_economy_2024_clean.csv`
  → Dataset final limpio y preparado para futuros análisis.

## 🧠 Objetivos del análisis

- Explorar la estructura de los datasets de movilidad y economía.
- Limpiar y estandarizar la información para garantizar su calidad.
- Integrar ambas fuentes de datos mediante columnas comunes.
- Analizar la relación entre indicadores de congestión vehicular y productividad económica.
- Identificar tendencias e insights que apoyen la toma de decisiones basada en datos.
